# 👨‍💻 Portfolio Personnel — Abderrahim Meziane

Bienvenue sur le dépôt de mon site web personnel. Ce portfolio a été conçu pour présenter mon parcours d'étudiant en **Licence d'Informatique à Sorbonne Université**, ainsi que mes projets techniques.

🔗 👉 **[Voir le site en ligne](https://abderrahim-meziane.github.io/My_Portfolio/)** 

## 🛠 Technologies utilisées
Ce site est développé en **Front-End** pur, sans framework lourd, pour garantir rapidité et simplicité. Le formulaire de contact s'appuie sur un petit back-end **Node.js** fait maison.

* **HTML5** : Structure sémantique.
* **CSS3** : Design personnalisé (thème sombre) et animations.
* **Bootstrap 5** : Pour la grille responsive et la navigation mobile.
* **JavaScript (ES6)** : 
    * Animation "Machine à écrire" sur la page d'accueil.
    * Envoi du formulaire de contact (fetch) vers ma propre API.
    * Logique de navigation et fermeture automatique du menu mobile.

## ✨ Fonctionnalités clés
* **Design Responsive :** S'adapte parfaitement aux mobiles, tablettes et ordinateurs.
* **Animations dynamiques :** Effet de frappe automatique pour la présentation.
* **Formulaire de contact :** géré par ma propre API **Node.js** (dossier [`contact-api/`](contact-api/)), qui m'envoie les messages par e-mail.
* **Navigation fluide :** Défilement doux (Smooth scrolling) entre les sections.
